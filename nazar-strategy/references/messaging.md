# Messaging

## Tagline directions (show 3, with 3 lines each)
| Direction | Does | Example shape |
|---|---|---|
| Descriptive | Says what or where, clearly | "Roasted Tuesday, in your cup by Friday." |
| Provocative | Takes a stance | "Slow food, fast hands." |
| Poetic / local | Rhythm, rhyme, a proverb rewritten, local language | "I ♥ NY" (a rebus) / a local proverb rewritten |
Tests: say it aloud (rhythm), and it must not need the logo beside it to make sense. It must be ownable (not a category cliché: "taste the difference"), and it must survive translation or deliberately not need it. Check that it isn't already a registered slogan. **Lock the tagline before identity work**, because a later change ripples through every lockup.

## Messaging house
- **Roof:** the brand idea (one sentence)
- **Pillars (3):** what we say, each with 2–3 proof points (real facts, numbers marked "sample" if not real)
- **Foundation:** beliefs and personality
Every headline, caption and pitch should trace back to one pillar.

## Elevator lines
- **5 seconds:** name + onlyness ("<Name> is the only <category> that <differentiator>.")
- **30 seconds:** problem → idea → proof
- **Bio lines** for Instagram (2 lines, both languages) and LinkedIn (one sentence)

## Voice seeds (handed to the brand book's voice page)
Three traits as "X, not Y", a copy device (a repeatable sentence shape), 5 words the brand uses and 5 it never uses, and one line written in 3 tones (sober, warm, playful) to set the dial.

## Bilingual messaging
Write each line natively in each language rather than translating. A transliterated local language (Roman Urdu, Hinglish, Arabizi…) is a first-class voice. Test lines with native speakers of each audience.
