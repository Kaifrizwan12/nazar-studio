# Story lessons

- 2026-11-21: Show every product's front and back exactly once. Never reuse a layout device or the same pack image in one story. Compose overlaps (front-back pairs, fans, tosses) as one RGBA, so the overlap guard still passes.
- 2026-11-21: Keep pack art clean on story pages. No numbered callouts or arrows on the pack. Explain the rules beside the pack, as a list.
- 2026-11-21: Use no AI scene photos unless the owner picks one. Here one flat-lay was kept and the rest were parked.
- 2026-11-21: Include a measured flats page (every structure with grams and mm). It reads as a real job and answers the printer's first question.
- 2026-11-21: The studio contact page (mark, one line, founder, email, phone, social) goes before thank-you, never after it. Use owner-supplied details only.
- 2026-11-21: Show the full contact sheet before shipping. The owner reviews by page number, so fix that page, then hunt the same class of problem on every page.
