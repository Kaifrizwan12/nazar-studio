# Lessons from real work (nazar-core)
Format: date, what happened, evidence, change made. Generic on purpose: no client names or private data.

- 2026-11-21 · Reading slide text needed macOS · On Windows the tesseract installer often isn't on PATH. · `engine/read_text.py` now finds tesseract (TESSERACT_CMD, PATH, C:\Program Files\Tesseract-OCR), then pytesseract, prepares the slide per tessdoc (invert dark, upscale, border, psm 11, TSV boxes) and says what to install if neither; `references/research_ocr.md`, `engine/test_read_text.py`.
- 2026-11-23 · The brief step under-read a long multi-job brief · A full-studio brief (identity, packaging, shoot, motion, web, campaign, case study) showed only its first 300 characters with no marker; auto-tagging kept 2 jobs; there was no campaign tag, so posters and social fell through. · `tags.prompt_line` shows the whole prompt or marks the cut, auto-tagging keeps every job it finds, a `#campaign` tag was added; `engine/test_tags.py` (4 of its 5 cases fail on the old code).
- 2026-11-23 · The scaffold could not follow a brief's own folder map · A brief named its folders (00_brief, 02_brand, 03_packaging, 04_photo … 99_archive); the scaffold's fixed names clashed and its files had to be moved by hand. · `scaffold.py init --layout "KEY=folder,…"`, saved in `.claude/nazar.json` and used by archive, release and status; covered in `scaffold.py --selftest`.
- 2026-11-23 · Projects copied the engine to change brand.json · The copy wrote into its own folder, would never get engine fixes, and `qa_views.py` crashed in it (it imports a sibling kit). · `lib.py` reads `NAZAR_BRAND=/path/brand.json` and resolves its paths (fonts, logos, exports, page modules, osm, out) from that folder; `qa_views.py` and `chain_check.py` stop with a clear message outside the skills folder; README and SKILL say never copy; `engine/test_brand_env.py`.
- 2026-11-21 · Brand files arrived late or wrong · Square backdrops got resampled to 4:5 and dark logos got boxed on dark slides. · `tags.py` asks up front for native 4:5 light and dark backdrops and a light-on-dark logo, checks ratio and transparency, and lists what is still missing in the profile; the social and backdrops intakes and the pattern template ask the same; `engine/test_profile_files.py`.
- 2026-11-23 · An owner reframe of the brief had no home · The owner molded the brief mid-project (a fixed point retired, a new positioning); the change lived only in chat and the decisions log, and the brief file still said the old thing. · `project_playbook.md` rule: BRIEF_DELTA (changes / stays), decisions-log entry, next brief version as untouched client pages + amendment pages, old version to `_superseded/`.
- 2026-11-23 · CI selftest failed on every push since the brand-env test · `test_brand_env.py` renders through cairosvg, and the macOS runner has no libcairo ("cannot load library libcairo.2.dylib"). · selftest.yml: `brew install cairo` and `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib`.
- 2026-11-23 · Self-QA passed work that an outside eye scored 4.5/10 · The maker's QA missed a dial lookalike, sub-minimum foil lines, a weak name and a wrongly built foil master; a fresh agent given only the images and criteria caught all of them. · qa_design.md: "Independent reviewer" method + an independent review gate before showing (fix P1/P2, re-run until clean, report the score).
