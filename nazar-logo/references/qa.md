# Logo QA (on top of `../nazar-core/references/qa_design.md`)

## Idea
- [ ] The mark carries the brand idea, and its one-sentence story is true when you look at it
- [ ] It's distinctive on the competitor wall, and isn't a category cliché or a lookalike
- [ ] It works in flat black (no effect is doing the work)
- [ ] The semiotic choice (icon / index / symbol) is deliberate

## Drawing
- [ ] Minimal anchor points on extrema; smooth curves with no kinks or stray points
- [ ] Consistent radii, angles and stroke family
- [ ] Optical corrections applied: overshoot, stroke contrast, visual-mass centring, ink traps where needed
- [ ] Even typographic colour in the wordmark; kerning is checked at large and small sizes
- [ ] Bilingual scripts match in visual weight and alignment

## Tests
- [ ] Blur, 16 px, one colour, reversed, on photos, colour-blind simulation: all pass
- [ ] Material tests done where relevant (embroidery, stamp, vinyl, signage)
- [ ] Minimum sizes are set from real tests

## Files
- [ ] Every lockup × colour × format is exported and named to the convention
- [ ] SVGs are clean (outlined text, no hidden or empty layers, tight viewBox) and open correctly in a browser
- [ ] Colour values are consistent across all files; a profile is embedded where needed
- [ ] Favicon and app icon are checked at real size on a real device or simulator
- [ ] README and quick guide included; font licences are noted

## Legal and records
- [ ] Trademark first pass recorded in `research/logo/clearance.md`, with the attorney recommendation stated
- [ ] No unlicensed font or third-party element in the mark
- [ ] `SPEC.md` updated with the locked mark, colours, minimum sizes and clear space
