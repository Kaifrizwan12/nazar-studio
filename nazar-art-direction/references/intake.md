# Art direction intake

1. **What's needed?** Photography (product, people, place, events) / illustration / icons / all.
2. **Use:** social / web / packaging / OOH / print / editorial / a library for the team.
3. **Point-of-view options:** 3 one-line directions, each with 3 references and the named qualities.
4. **The dial-up:** cinematic (film light, letterbox, grain, scene composition) / pop (saturated colour, flash, graphic styling) / documentary (natural, unposed) / still-life precision.
5. **Production level:** phone and in-house / a photographer with a small crew / a full production.
**Plain text:** products and quantities, people available (staff, customers, models), locations and access, dates, budget, the photographer or illustrator (if chosen), usage rights needed (where, how long), existing imagery.
