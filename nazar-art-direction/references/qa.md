# Imagery QA (on top of core `qa_design.md`)

## Photography
- [ ] Every image fits the one-line point of view
- [ ] Light, grade, crop and composition follow the style rules; the set looks consistent side by side
- [ ] Space for type where the layout needs it; crops checked at every ratio
- [ ] Skin tones and product colours true; retouching honest
- [ ] No stock, no AI images
- [ ] Releases and licences recorded in `RIGHTS.md`

## Illustration
- [ ] Matches the style guide (construction, line, colour count, detail)
- [ ] Reads at the smallest use size
- [ ] Rights and credits recorded; source files delivered

## Icons
- [ ] On the grid with the keylines; one stroke, radius and angle set
- [ ] Optically balanced as a set (blur test side by side)
- [ ] Readable at 16 px; meaningful icons have text labels or accessible names
- [ ] SVGs clean (single paths, `currentColor`), named consistently, with an overview sheet
