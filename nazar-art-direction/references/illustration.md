# Illustration

## When to illustrate
When the subject can't be photographed (ideas, processes, the future), when the brand needs warmth or wit, when consistency across many subjects matters, or when it's cheaper than shoots.

## Style guide (so anyone can extend it)
- **Construction:** geometric vs organic; built from the brand's atom or grid where possible
- **Line:** none / single weight / variable; the weight relative to the canvas
- **Shape and fill:** flat / texture (grain, halftone, riso-style) / gradient (rarely)
- **Colour:** a limited palette from the brand (a set number of colours per illustration)
- **Perspective:** flat, isometric or naive; light source
- **People:** proportions, faces (detailed / minimal / none), diversity, gestures
- **Detail level** at the smallest use size
- **Do / don't** with 6 examples each
- **Texture** follows the brand's texture rules (see `nazar-brand-book` graphic language)

## Commissioning an illustrator
A brief with the brand idea, uses, style guide (or the brief to create one), subjects list, sizes and formats, deadlines, rounds of revisions, fee, and **usage rights** (where, how long, exclusivity). Source files delivered in vector or layered form. Credit the illustrator where possible.

## Consistency
Keep one master file of approved illustrations as the reference set. New pieces are checked side by side against it. Never generate "in the style of" an artist with AI.
