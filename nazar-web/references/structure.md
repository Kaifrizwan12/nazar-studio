# Structure

## Sitemap and journeys
- List the 3–5 main visitor types and what each needs to do. Draw the shortest path for each.
- Keep navigation to 5–7 top items; the primary action is always visible.
- Every page has a purpose statement: "This page helps [visitor] to [do X]."

## Landing page anatomy (adapt, don't copy)
1. **Hero:** what it is plus why it's different (the onlyness statement, rewritten as a headline), one primary action, and a real visual.
2. **Proof:** clients, numbers (real or marked "sample"), press, testimonials.
3. **How it works / what you get:** 3 steps or 3 benefits, specific.
4. **The story / signature section:** where the brand's idea gets its moment (a cinematic scroll, an interactive element).
5. **Details:** features, menu, products, cases.
6. **Objections:** FAQ, pricing clarity, guarantees.
7. **Final call to action** and a useful footer (contact, locations, social, legal).

## Copy rules on the web
- Headlines say something specific. "Fresh coffee, roasted weekly in [city]" beats "Elevate your mornings".
- Scannable: short paragraphs, meaningful subheads, front-loaded sentences.
- Buttons say what happens ("Book a table", not "Submit").
- Write in the brand voice; local language where the audience lives.
- Every image has alt text that describes it.
