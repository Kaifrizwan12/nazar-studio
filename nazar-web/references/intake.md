# Web intake

1. **What's the site for?** Sell (e-commerce) / generate leads / present the brand and story / portfolio and cases / hiring / product documentation.
2. **The one primary action** visitors should take.
3. **Platform:** custom build / Webflow / Framer / Shopify / WordPress / undecided (recommend based on who maintains it).
4. **Who maintains the content?** (This decides CMS structure and component flexibility.)
5. **Signature moment:** a scroll story / an interactive hero / a cinematic section / a playful detail / restraint only.
**Plain text:** current URL and analytics access, sitemap needs, real copy (or who writes it), photography and video available, languages (and RTL?), integrations (forms, booking, payments, CRM), domain, deadline, the developer (if chosen).
